# BELIVEIN Mini App — Railway

Telegram Mini App на Node.js / Express 5 с PostgreSQL.

## Развёртывание

1. Загрузите содержимое репозитория в GitHub.
2. Подключите PostgreSQL к сервису в Railway.
3. Укажите переменные Railway:
   - `BOT_TOKEN` — токен Telegram-бота от BotFather.
   - `ADMIN_IDS` — Telegram ID администраторов через запятую.
   - `DATABASE_URL` — ссылка на PostgreSQL Railway.
   - `WEBAPP_URL` — публичный HTTPS URL приложения.
   - `CHANNEL_USERNAME` — канал для проверки подписки; по умолчанию `@BELIVEIN_OG`.
4. Railway запускает проект командой `npm start`. Требуется Node.js 20+.
5. Открывайте Mini App через Telegram, чтобы сервер мог проверить `initData`.

## DOUBLE

- Ставки принимает сервер через `/api/double/bet`; баланс блокируется и списывается в PostgreSQL в транзакции.
- Серверный раунд длится 30 секунд. Результат и выплаты фиксируются в таблицах `double_rounds` и `double_bets`.
- Вероятности: красное 49,5%, чёрное 49,5%, зелёное 1%. Красное/чёрное выплачивает 2x, зелёное — 14x.
- Для ставок требуется подключённая PostgreSQL и действительная Telegram-сессия.
- Счётчики на кнопках включают симулируемую активность ботов для визуального эффекта; ставки ботов не списывают пользовательские средства и не участвуют в выплатах.
- На текущей реализации серверный синхронизатор раундов рассчитан на один работающий экземпляр приложения Railway. Не запускайте несколько реплик без отдельного распределённого координатора раундов.

## Кейсы и бесплатный кейс

- Обычные кейсы и содержимое настраиваются в профиле администратора → «Админ-панель».
- Бот должен быть администратором канала или иметь достаточные права, чтобы Telegram Bot API мог достоверно проверить членство.

## Последнее обновление интерфейса

- Исправлено отслеживание завершившихся раундов DOUBLE: результат берётся из серверной истории с `round_id`, поэтому опрос состояния не теряет запуск анимации. Угол колеса вычисляется для точного попадания серверного номера под указатель.
- Добавлен горизонтальный промо-слайдер игр на главной: автоматическое перелистывание каждые 7 секунд и ручной свайп.
- Добавлены атмосферные анимированные градиенты и дымчатые свечения.
- Добавлен синтезируемый тихий фоновый саундтрек с переключателем и регулировкой громкости в настройках. Воспроизведение начинается после пользовательского действия из-за ограничений автозапуска браузера.

Перед публикацией проверьте игру на тестовом аккаунте Telegram и в Railway: внешняя среда и база данных здесь не запускались.
